# Swap a seat's agent

## `agent-teams sessions swap`

```bash
agent-teams sessions swap <run> --seat <id> --agent <agentspec>
```

Swaps the seat's session to another agent **in place** — the conversation and
the files carry, the harness's own state does not — and tells the supervisor
in a sentence, the way a swap of an agent-runtimes session tells the new agent:
*This conversation was with Claude Code until turn 4; from here it is with
Codex. What was said stays; what Claude Code kept for itself waits for a swap
back.*

What the verb refuses, in a sentence:

| Refusal | The sentence |
|---|---|
| The seat's turn runs (409) | *Seat reviewer is answering its task: swap it when the task is over, or interrupt it first.* |
| The seat's session is not the run's (422) | *Seat reviewer's session is not the run's: it kept none (a remote worker's session is its own); only a harness or a model seat is swapped.* |
| No such seat | *Team coding-agents has no seat 'tester': one of coder, reviewer.* |
| The agent already bound | *Seat coder's session is bound to shield-mvp-claude-code already.* |
| An ended run | *Team session X ended: clone it to go on from it, then swap the clone's seat.* |

## Where the swap happens

The swap runs where the seat's session is, through the control plane's
`executions.swap-seat`, which alone reaches the seat's runtime. Between a
seat's tasks the runtime of its last task has usually ended and the session
is paused in the record: the `swapped` entry is written there with the
sentence the new agent is told, and the seat's next task is served from the
agentspec it was swapped to. When a runtime still holds the session, it is
swapped in place through the session API. Either way the run carries the
swap and the supervisor is steered with the sentence, as you; the verb says
whether it was told:

```text
$ agent-teams sessions swap exec_8f1c… --seat coder --agent shield-mvp-codex
Seat coder swapped to shield-mvp-codex in the record (session 01m5…): This
conversation was with Claude Code until turn 2; from here it is with Codex.
What was said stays; what Claude Code kept for itself waits for a swap back.
The supervisor was told.
```

A cloned or imported team session that has no run yet is resumed first
(*Team session X has no run yet: resume it, then swap the run's seat*). With
`--local`, a self-hosted server's runner holds the agent's process, and a swap
there is not built yet.
